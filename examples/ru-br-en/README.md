# Russian / Brazilian Portuguese / English example

An optional 248-name editorial research preset derived from the original app. Every participant rating is neutral. Personal family fields, workbook provenance, preference colors, conversations, source archives, and database state are excluded.

Select with `node scripts/configure.mjs ru-br-en`. The preset retains stable candidate IDs, editorial assessments, and linked sources. It has complete document-spelling, cultural-context, and household-form records for 248 candidates, with detailed full-name pronunciation notes for 21. Its source checks date to November 2026; the evidence is a research snapshot. Cultural associations, proposed spellings, and household recommendations are scoped editorial assessments rather than universal naming rules.

Research distinguishes documented forms, related-name evidence, linguistic inferences, and proposed family adaptations. Recorded use is not ethnic exclusivity or a popularity claim. Document spelling comparisons do not establish that a registration or passport authority will accept a particular spelling. Detailed pronunciation coverage is limited to the records included.

Source titles, dates, locators, and URLs remain with the research. Third-party source pages and documents retain their own terms. The preset includes editorial notes and links; it does not include original downloaded PDFs, spreadsheets, or source-page text archives.

The configuration API is described in [the configuration guide](../../docs/CONFIGURATION.md).
